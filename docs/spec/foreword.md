# Foreword

The Ronin Programming Language is an experimental reactive candygrammar suitable for scripting interactive computer-based games.

The original motivation was to create a language which was readable by non-programmers, while being easy to learn by practitioners.

The principal inventor of Ronin is Eric Budai.  Development started in 2022, and is named after a cat.

### Goals
- Readability
- Straightforward reactive programming (eg: let x = y + 5)
- Minimization of boilerplate

### Non-Goals
- Be a "systems language"
